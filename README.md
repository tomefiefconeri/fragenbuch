# Fragenbuch

Kleine Fragen, festgehalten. Statische Web-App (GitHub Pages) mit Supabase als Datenbank.

- Frage, Antwort, Quelle, Tags, Datum, „Wo kam die Frage auf?“, Status (offen/beantwortet)
- Volltextsuche, Filter nach Status und Tags, Zufallsmodus 🎲
- Login per E-Mail und Passwort, Daten per Row Level Security geschützt (jeder sieht nur seine eigenen Einträge)
- Als App auf den Homescreen legbar (PWA-Manifest)

Tastenkürzel: `/` fokussiert die Suche.
